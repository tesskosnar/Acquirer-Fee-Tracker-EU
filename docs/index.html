Jak číst výsledek

  • Efektivní sazba = procentní poplatek + pevná část přepočtená kurzem ČNB, děleno hodnotou transakce.
  • MIN/MAX přepíná spodní a horní hranici u veřejných rozpětí.
  • Měsíčně násobí poplatek počtem transakcí a přičítá veřejný měsíční paušál, pokud je uveden.
  • Individuální nabídky se zobrazí, ale nevstupují do cenového žebříčku.
  • Acquirer, PSP, gateway a A2A/wallet jsou metodicky oddělené typy.
